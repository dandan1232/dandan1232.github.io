# 候鸟笔记背景设计

## 目标

将 MIT 许可的 `sdhhhyu-glitch/Migration-OpenSource` Canvas 候鸟场景用作 `/notes/` 列表页及全部文章页的固定背景，保留现有笔记内容、导航和主题切换。

## 方案

- 复用原项目的纯 Canvas 渲染器，作为同源、固定定位的背景 iframe。
- 删除视觉背景不需要的原站 UI、诗句、音频、全屏、横屏锁定和屏幕常亮行为。
- 由共享 `theme.js` 在所有笔记页统一创建背景，并把父页面指针位置同步给鸟群。
- 暖色主题使用 `WARM / 暖纸` 场景，深色主题使用 `NIGHT / 夜航` 场景。
- 笔记卡片和文章容器使用半透明实色与适度模糊，确保长文、代码和表格的可读性。

## 响应式与无障碍

- 背景不接管点击、触摸或滚轮，笔记交互和页面滚动保持原样。
- 触屏设备沿用源项目的低鸟群数量，并取消源项目强制横屏布局。
- `prefers-reduced-motion: reduce` 下只绘制静态场景，不持续请求动画帧。
- 页面不可见时暂停渲染，重新可见后继续。

## 验证

- 运行 TypeScript 检查及 Vite 生产构建。
- 分别检查笔记列表、文章详情、暖色/深色主题。
- 检查桌面、手机视口及 reduced-motion 模式。
- 确认控制台无异常、背景不遮挡内容且不拦截交互。
